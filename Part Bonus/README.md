## Project Description
This project demonstrates a working implementation of an on-device LLM using the [MediaPipe LLM Inference sample](https://github.com/google-ai-edge/mediapipe-samples/tree/main/examples/llm_inference/android). It brings conversational AI to Android devices without dependency on the cloud, enabling low-latency and private interaction. To see source code, navigate to the source code directory then mediapipe-samples > examples > llm_inference. Important files are commented to display full understanding.

## Technical Depth
Deploying an LLM on a mobile device includes several difficulties. This project explores:
- LLMs optimized for mobile use
- Model integration using MediaPipe's LLM Inference APIs
- Inference on CPU and GPU backends
- Building a lightweight responsive UI for interaction
