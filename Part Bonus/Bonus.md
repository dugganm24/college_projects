# Bonus

## Problem and Learning Objectives
On device LLMs are an innovation in mobile deep learning, helping to enable responsive and private AI applications without requiring any cloud access. In this project, the group was able to explore the Android implementation of an on-device LLM using Google's MediaPipe sample repository. 

**Learning Objectives:**
- Understand the architecture and flow of a mobile app running an on-device LLM
- Gain experience deploying quantized LLM models to Android using MediaPipe and TensorFlow
- Learn how to interact with the model via UI components and customize the prompt and response handling pipeline
- Understand the constraints and optimization techniques for deploying LLMs on smartphones with limited resources

## Deliverables
- A working Android application (apk) with on-device LLM chat capability
- Commented soruce code to show understanding of implementation
- A screen recording of the app's usage
- A voiceover explanation of the app's interface
- A writeup describing the project setup, app overview, and key features
- A Bonus document (this file)
- A README including team information and reflection on the technical depth
