# Syllablast
__Project Overview__  
This project involves the development of a React-based word puzzle game called Syllablast. The game consists of three 4x4 grid configurations where users swap the locations of two syllables to reveal four completed words. Players maximize their scores by successfully completing all words within the configuration.

__Project Objectives__    
 - Design an interactive word puzzle game using React and TypeScript.
 - Implement a dynamic 4x4 grid system for syllable swapping.
 - Ensure a smooth and responsive user experience.
 - Provide real-time feedback on word completion and scoring.

__Technologies Used__    
 - **React**: Frontend framework for building the user interface.
 - **TypeScript**: Ensures type safety and maintainability.
 - **CSS & Styled Components**: Enhances UI styling and responsiveness.
