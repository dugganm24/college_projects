__Learning Notes__

Throughout the exploration of the Sunflower app, the group was able to gain valuable insights into several best practices in Android development and architectural patterns of Android projects. Building off the Todo sample, this project provided us a deeper understanding of several concepts of Android development including MVVM architecture, the utilization of external APIs, more Compose UI techniques, Room database integration, and Gradle.

The Sunflower app built off the Todo app to provide the group a deeper understanding of Model-View-ViewModel (MVVM) architecture in a slightly more complex application. Throughout our exploration of this app, we were able to see how ViewModel files act as the intermediary between the UI and data layers of this app. For example, in PlantDetailViewModel.kt, the plantId is retrieved from SavedStateHandle. From there, the plant LiveData is populated from fetching data from PlantRepository. Furthermore, the isPlanted StateFlow from GardenPlantingRepository shows how the ViewModel shows data streams to the UI to display. The addPlantToGarden() function encapsulates the logic for database interactions which helps in keeping the UI layer clean. The separation of functionality in different layers of each component shows how MVVM architecture is effective in managing UI states and data flows. 

One new integration the group was able to learn about in this project is the integration of external APIs. In this project, the Sunflower app utilized the Unsplash API to get images to populate for each plant. The hasValidUnsplashKey() method in PlantDetailViewModel.kt shows how the app checks for a valid API key, which then determines if the Gallery icon is displayed. This is used to conditionally enable gallery features, which shows how to manage API dependencies. The use of GlideImage in PlantImage in PlantDetailView.kt to load images from URLs provided from the Unsplash API shows how to integrate external image loading libraries.

The Sunflower app also expanded the group's understanding of Compose UI development through the use of more external libraries, like Glide. The PlantImage composable in PlantDetailView.kt uses GlideImage to load images from URLs, which is an efficient way to handle image loading in Compose. The inclusion of RequestListener in GlideImage showed how to manage any loading states and errors when retrieving images. The use of AndroidViewBinding in PlantDescription composable in PlantDetailView.kt to dsiplay HTML formatted text shows how to integrate traditional Android views into Compose UI when needed, which can be helpful wehn dealing with features that are not yet in Compose. The PlantToolbar and PlantHeaderActions composables demonstrate how to create dynamic top app abrs that change based on the scrolling state, which helped the group's understanding in how to implement complex UI behaviors in Compose. 

This app also provided the group a deeper understanding off Room's capabilities, in particular surrounding the management of related data entities. For example, the GardenPlantingRepository and GardenPlantingDao work together to handle database operations related to garden plantings. The createGardenPlanting() function in GardenPlantingRepository.ky shows how to insert data into the database, and isPlanted() shows how to query the database to check if a plant is in the garden already. This interaction between the repository and the DAO shows Room's role in abstracting database operations and providing clean APIs for data access.

The use of BuildConfig.UNSPLASH_ACCESS_KEY in PlantDetailViewModel shows how Gradle build configurations can be used to manage environment variables. This approach ensures that API keys are not hardcoded into source code for security reasons. The Gradle wrapper also ensures consistent builds. These Gradle features expanded the group's knowledge of the use of Gradle in Android apps.  

Overall, the Sunflower app provided a great stepping stone from the Todo app to enhance our understanding of familiar concepts as well as introduce some new ones. We gained valuable insights into architectural patterns, UI development, dependency injection, and asynchronous operations. This project was a great example of how to build large maintainable Android applications.
